    {{NOTICE}}

    처음 왔어요설치 프로그램으로 5분이면 서버에 들어가요 0 / 6
    1. 준비물 확인자바 에디션 + 공식 런처

      마인크래프트 자바 에디션(PC 버전)이 있어야 해요. 휴대폰, 콘솔, 윈도우 스토어의 베드락 에디션으로는 들어올 수 없어요.

      마인크래프트 공식 런처로 게임을 한 번이라도 켜 본 적이 있으면 준비 끝이에요.

    2. 설치 프로그램 실행더블클릭 한 번이면 끝 · Windows

      Fabric 설치, 모드·설정 넣기, 서버 등록까지 프로그램이 알아서 해요. 예전 모드랑 섞이지 않게 노천극장 전용 폴더를 따로 써요.

      노천극장 설치 프로그램 받기Windows · NOCHEN-SETUP
      1. 마인크래프트 런처를 닫아요. 켜져 있으면 프로그램이 닫을 때까지 기다려요
      2. 받은 nochen-setup.zip을 압축 풀고, 나온 NOCHEN-SETUP을 두 번 눌러 실행해요.
      3. 파란 창 "Windows의 PC 보호"가 뜨면 추가 정보 → 실행을 눌러요. 직접 만든 프로그램이라 처음 한 번 뜨는 경고예요
      4. 검은 창이 알아서 진행돼요. 마지막에 "예전 모드를 정리할까요?"라고 물으면 Y(정리) 또는 N(그대로)을 누르고 Enter.

      모드가 업데이트되면 같은 프로그램을 다시 실행하면 돼요. 노천극장 폴더의 모드만 깨끗하게 바뀌어요.

      macOS는 아직 설치 프로그램이 없어요. 아래 5단계 "직접 설치하기"를 따라 해 주세요.

    3. 게임 실행런처에서 노천극장 고르기
      1. 마인크래프트 런처를 켜요.
      2. 플레이 버튼 왼쪽 목록에서 {{G_SETUP_PROFILE}}을(를) 골라요. 직접 설치했다면 fabric-loader-{{G_VERSION}}
      3. 플레이! 처음에는 이것저것 받느라 시간이 좀 걸려요.
      게임이 안 켜지거나 오류가 나요
      • 설치 프로그램을 한 번 더 실행해요. 모드를 처음부터 다시 깔아 줘요.
      • 런처에서 다른 버전(최신 릴리스 등)을 고르지 않았는지 확인해요.
      • 그래도 안 되면 오류 화면을 캡처해서 아래 도움 카드의 디스코드로 보내 주세요.
    4. 서버 접속멀티플레이에 이미 들어 있어요

      멀티플레이를 누르면 서버가 이미 목록에 있어요. 두 번 누르면 접속!

      목록에 없으면 서버 추가를 눌러 아래 주소를 넣어요.

      {{G_ADDR_ROW}}
    5. 직접 설치하기프로그램이 안 될 때 · macOS

      설치 프로그램이 잘 됐다면 건너뛰어도 돼요.

      1. Fabric 설치: 아래 버튼으로 Fabric 설치기를 받아 실행하고, Minecraft 버전을 {{G_VERSION}}으로 맞춘 뒤 설치. 버전이 다르면 서버에 못 들어와요
        {{G_LOADER_LINKS}}
        설치기가 안 열리면 adoptium.net에서 Java를 먼저 설치해요
      2. 모드 넣기: 아래 모드 받기로 mods.zip을 받아요. mods 폴더를 열어 예전 파일을 전부 지우고, 압축을 푼 .jar를 전부 넣어요.
        %appdata%\.minecraft\mods
        ~/Library/Application Support/minecraft/mods
        Win + R → 경로 붙여 넣기 → EnterFinder에서 ⌘ ⇧ G → 경로 붙여 넣기
      3. 설정 넣기: 설정 파일을 받아 압축을 풀고, 나온 폴더들을 .minecraft 폴더(mods 한 칸 위)에 덮어쓰기.
        {{G_CONFIG_DL}}
      4. 실행: 런처에서 fabric-loader-{{G_VERSION}}을 골라 플레이, 멀티플레이 → 서버 추가에 위 주소를 넣어요.
      "오류"가 나요 (Fabric 관련)
      • mods 폴더에 예전 모드나 fabric-api 같은 남은 파일이 섞이면 생겨요. mods 폴더를 싹 비우고 받은 파일만 다시 넣어요.
    6. 그래도 막히면사진 설명 · 문의

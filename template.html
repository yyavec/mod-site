  1. 준비물 확인자바 에디션 + 공식 런처

    마인크래프트 자바 에디션(PC 버전)이 있어야 해요. 휴대폰, 콘솔, 윈도우 스토어의 베드락 에디션으로는 들어올 수 없어요.

    마인크래프트 공식 런처로 게임을 한 번이라도 켜 본 적이 있으면 준비 끝이에요.

  2. {{G_LOADER}} 설치모드를 돌려 주는 프로그램 · {{G_VERSION}}

    모드를 쓰려면 먼저 {{G_LOADER}}을(를) 설치해야 해요. 아래 버튼에서 설치 파일을 받으세요.

    {{G_LOADER_LINKS}}
    1. Java가 없으면 먼저 설치해요. adoptium.net에서 Download를 눌러 받고, 설치는 전부 기본값으로 넘기면 돼요. 마인크래프트 런처 안의 Java로는 설치 파일이 안 열려요
    2. 받은 설치 파일을 두 번 눌러 실행해요. 마인크래프트가 열려 버리면? 설치 파일 우클릭 → 연결 프로그램 → 다른 앱 선택 → OpenJDK Platform binary(Java) → 항상 이 앱 사용 체크
    3. Minecraft 버전을 {{G_VERSION}}(으)로 맞춰요. 버전이 다르면 서버에 못 들어와요
    4. 클라이언트 설치(Install client)가 선택된 상태로 설치(OK)를 누르고 끝날 때까지 기다려요.
    {{G_VERSION_NOTE}}
  3. 모드 · 설정 넣기mods 폴더에 모드, .minecraft에 설정 덮어쓰기
    1. 이 안내 바로 아래 모드 받기 버튼으로 mods.zip을 받아요.
    2. Win + R을 누르고 아래 경로를 붙여 넣은 뒤 Enter.Finder에서 ⌘ ⇧ G를 누르고 아래 경로를 붙여 넣어요. 폴더가 없으면 mods라는 이름으로 새로 만들어요.
      %appdata%\.minecraft\mods
      ~/Library/Application Support/minecraft/mods
    3. 폴더 안에 예전 모드가 있으면 전부 지우고, 받은 zip의 압축을 풀어 나온 .jar 파일을 전부 넣어요.
    설정 파일 덮어쓰기처음 한 번만

    서버와 같은 설정으로 맞추는 파일이에요. 이걸 안 하면 퀘스트, 지도, 몹 설정 등이 서버와 달라질 수 있어요.

    {{G_CONFIG_DL}}
    1. 받은 zip의 압축을 풀면 config, defaultconfigs 폴더 두 개가 나와요.
    2. .minecraft 폴더를 열어요. mods 폴더보다 한 칸 위예요.
      %appdata%\.minecraft
      ~/Library/Application Support/minecraft
    3. 두 폴더를 그대로 붙여 넣고, "이미 있다"고 물어보면 덮어쓰기(모두 바꾸기)를 눌러요.
    .minecraft
├─ mods            ← 모드 .jar 파일들
├─ config          ← 덮어쓰기
└─ defaultconfigs  ← 덮어쓰기
  4. 게임 실행런처에서 {{G_LOADER}} 버전 고르기
    1. 마인크래프트 런처를 켜요.
    2. 플레이 버튼 왼쪽의 버전 선택을 눌러 {{G_PROFILE}}을(를) 골라요.
    3. 플레이! 처음에는 이것저것 받느라 시간이 좀 걸려요.
    게임이 안 켜지거나 오류가 나요
    • 예전 모드가 남아 있는지 mods 폴더를 다시 확인해요. 받은 파일 말고 다른 파일이 있으면 지워요.
    • 버전이 맞는지 확인해요. 런처에서 고른 버전과 설치한 버전이 같아야 해요.
    • 모드팩이 무거워서 메모리가 모자랄 수 있어요. 런처 → 설치 설정 → 해당 버전 편집 → 추가 옵션의 JVM 인수 맨 앞 -Xmx2G를 -Xmx6G로 바꿔요(컴퓨터 램이 16GB 이상일 때).
  5. 서버 접속멀티플레이 → 서버 추가
    1. 게임에서 멀티플레이 → 서버 추가를 눌러요.
    2. 서버 이름은 아무거나, 서버 주소에 아래 주소를 넣고 완료.
